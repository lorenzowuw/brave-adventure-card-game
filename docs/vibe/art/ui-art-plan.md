# UI 美术计划

## 目标

用 CSS/SVG 实现大部分 UI，AI 只提供复杂装饰和氛围参考。

## UI 总风格

- 羊皮纸底色。
- 冒险笔记边框。
- 手绘圈注、箭头、星标。
- 清晰卡牌信息优先。
- 不在图片里生成文字。

## UI 资产分流

| UI 元素 | 生成方式 | 原因 |
|---|---|---|
| 按钮 | CSS | 圆角矩形，纯样式 |
| 面板背景 | CSS | Style 可控 |
| 卡牌框 | CSS/SVG | 稀有度边框要动态变色 |
| HP/能量条 | CSS | 动态数值 |
| 地图连线 | SVG/CSS | 程序绘制更准 |
| 节点图标 | SVG 优先，必要时 AI | 小尺寸图标 |
| 装饰贴纸 | AI 可选 | 提升氛围 |
| 背景纹理 | AI 可选 | 羊皮纸/区域氛围 |

## 卡牌 UI 结构

```text
┌───────────────┐
│ 费用        稀有度角标 │
│               │
│   火柴人动作图 │
│               │
│ 技能名         │
│ 效果描述       │
└───────────────┘
```

## 地图 UI 结构

- 当前层：实色节点。
- 下一层：灰化节点。
- 未知：`????`。
- 已完成：打勾或淡化。
- Boss：皇冠或大轮廓。

## 战斗 UI 结构

- 上方：敌人信息和意图。
- 中央：战斗表现区。
- 下方：手牌。
- 底部：玩家 HP/能量/牌库/结束回合。

## 验收

- [ ] 文字全部由代码渲染。
- [ ] 稀有度颜色一眼可见。
- [ ] 地图节点 64px 可识别。
- [ ] 背景不影响可读性。
