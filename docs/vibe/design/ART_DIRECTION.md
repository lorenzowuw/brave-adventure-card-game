# 《勇者大冒险》Art Direction

> 基于 game-art-gen 资产分流规则：能代码画的绝不 AI 生成；AI 主要负责角色风格稿、背景氛围稿、复杂图标和关键宣传图。

## 核心视觉定位

**会动的冒险图鉴 + 火柴人奇幻冒险。**

- 主体角色：白色/浅色火柴人底模 + 1-2 个主题色特征。
- 世界观：原创轻奇幻，不使用真实人物、不使用版权角色。
- UI 感受：羊皮纸、冒险笔记、手绘圈注、涂鸦箭头。
- 动效感受：轻快、短促、反馈明确。

## 美术生产原则

1. **代码绘制优先**：纯几何、卡牌框、按钮、进度条、节点图标优先用 CSS/SVG/Canvas。
2. **AI 只做复杂或高识别度资产**：角色风格稿、敌人风格稿、区域背景氛围稿、特殊图标。
3. **火柴人统一底模**：圆头、简化躯干、四肢线条，2-4 头身比例。
4. **特征识别优先于精细度**：盾牌、兜帽、法杖、长发、钱袋、大锤等比五官更重要。
5. **小尺寸可读**：资产缩到 64-128px 仍能看出身份。
6. **避免版权风险**：不直接复刻任何已有 IP 角色或真实人物。

## 色彩规范

| 用途 | 颜色方向 | 说明 |
|---|---|---|
| 背景主色 | 米白/浅灰/淡羊皮纸色 | 降低战斗疲劳 |
| 线稿 | 黑/深灰 | 火柴人主体线条 |
| 玩家角色 | 每角色 1 个主题色 | 用于配饰、光效、卡牌边框 |
| 敌人 | 深灰 + 区域主题色 | 保持威胁感但不写实 |
| HP | 黄色/暖色 | 设计案指定黄色条 |
| 能量 | 蓝色 | 设计案指定蓝色条 |
| 护甲 | 绿色/青绿色 | 设计案指定绿色数字 |
| 稀有度 | 白/绿/蓝/紫/橙/红 | 与卡牌系统一致 |

## UI 视觉规范

- 卡牌：浅色底，稀有度边框，左上费用，中央火柴人动作图，底部效果文本。
- 地图节点：圆形或方形手绘图标，当前层清晰，下一层灰化/模糊，未知节点显示 `????`。
- 战斗界面：敌人区、战斗区、手牌区、玩家状态区清晰分层。
- 事件界面：冒险笔记卡片式布局，选项像贴纸按钮。
- 商店界面：货架/清单式，价格醒目。
- 结算界面：胜利用明亮金色，失败用灰紫色但不恐怖。

## 动画方向

| 动作 | 表现 | 时长 |
|---|---|---:|
| 出牌 | 卡牌飞到目标，轻微放大 | 0.3-0.5s |
| 攻击 | 火柴人冲刺/挥击关键帧，动作线 | 0.3-0.6s |
| 受击 | 目标抖动 + 红色伤害数字 | 0.2-0.4s |
| 护甲 | 蓝绿色护盾闪一下 | 0.3s |
| 回复 | 绿色上升数字 + 柔光 | 0.4s |
| 抽牌 | 从牌库飞入手牌 | 0.3s |
| 击杀 | 敌人碎裂/淡出 | 0.5s |

## 禁止事项

- 不生成精细写实插画作为主要角色资产。
- 不在 AI 图里生成中文字，文字统一由代码渲染。
- 不把 UI 面板、按钮、纯色卡框交给 AI 批量生成。
- 不直接引用或临摹版权角色。
- 不生成难以切图、边缘复杂但小尺寸不可读的资产。
