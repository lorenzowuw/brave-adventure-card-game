# 战斗系统设计

## 目标

提供快节奏、可读性强、数据驱动的单敌人回合制卡牌战斗。

## 战斗流程

```text
进入战斗
→ 初始化敌人
→ 初始化玩家 HP/能量/牌库
→ 开局抽牌
→ 玩家出牌
→ 玩家结束回合
→ 敌人执行意图
→ 新回合抽牌
→ 重复直到胜利/失败
```

## P0 范围

- 单玩家 vs 单敌人。
- 手牌、牌库、弃牌堆。
- 每回合固定抽牌数。
- 能量每回合恢复。
- 护甲每回合清空。
- 敌人意图循环。
- 胜利/失败结算。

## 战斗状态

| 字段 | 说明 |
|---|---|
| playerHp | 当前生命 |
| playerMaxHp | 最大生命 |
| playerEnergy | 当前能量 |
| playerMaxEnergy | 最大能量 |
| playerArmor | 当前护甲 |
| enemy | 敌人实例 |
| hand | 手牌 |
| deck | 牌库 |
| discard | 弃牌堆 |
| exhausted | 消耗区 |
| blessings | 当前祝福 |
| turnNumber | 回合数 |
| playerStatusEffects | 玩家状态 |

## 敌人意图

| 类型 | 效果 | P0 |
|---|---|---|
| attack | 对玩家造成伤害 | 是 |
| defense | 敌人获得护甲/恢复 | P1 |
| buff | 敌人增益 | P1 |
| debuff | 玩家减益/无视护甲伤害 | P1 |
| summon | 召唤 | P3 |

## 伤害计算

```text
最终伤害 = 基础伤害 × 稀有度倍率 × 被动加成 + 脆弱修正
暴击时 × 1.5
最终最小值为 1
```

## 回合规则

- 未使用能量回合结束清空。
- 护甲回合开始或结束清空，采用“新回合清空”策略。
- 手牌上限 10。
- 牌库不足时弃牌堆洗回牌库。
- 敌人意图必须在玩家行动前显示。

## 胜负条件

| 条件 | 结果 |
|---|---|
| enemy.currentHp <= 0 | 战斗胜利 |
| playerHp <= 0 | 本局失败 |

## 验收

- [ ] 战斗开始时手牌非空。
- [ ] 敌人意图可见。
- [ ] 出牌后能量减少。
- [ ] 敌人攻击先扣护甲再扣 HP。
- [ ] 玩家死亡后不能继续操作。
- [ ] 敌人死亡后发放奖励。
