# 祝福、共鸣与风险系统设计

## 目标

这些系统用于 P1 后增加变化和差异化，不阻塞 P0/P1 核心闭环。

## 祝福系统

### 定位

每次休息或战斗前，从祝福池随机给出 3 个正向增益，玩家选 1 个。

### MVP/P1 效果

| 祝福 | 效果 | 实现优先级 |
|---|---|---|
| 初始护盾 | 战斗开始获得护甲 | 高 |
| 思维敏捷 | 开局多抽 1 张 | 高 |
| 能量充盈 | 本场最大能量 +1 | 高 |
| 财运亨通 | 金币获取增加 | 中 |
| 绝境重生 | 首次低血回复 | 中 |

### 验收

- [ ] 休息时能三选一。
- [ ] 祝福进入局内状态。
- [ ] 下一场战斗能看到效果。

## 元素共鸣系统

### 定位

P3 差异化系统。根据出牌序列、角色与卡牌组合触发额外效果。

### 示例

| 条件 | 共鸣 | 效果 |
|---|---|---|
| 连续打出 3 张攻击牌 | 三重打击 | 第 3 张伤害翻倍 |
| 使用 3 张不同费用牌 | 完美节奏 | 抽 1 张 |
| 铁壁守卫 + 生命贤者卡 | 铁壁守护 | 每回合额外护甲 |

### 验收

- [ ] 出牌序列可记录。
- [ ] 条件匹配能触发一次。
- [ ] 首次触发能记入图鉴。

## 风险系统

### 定位

P3 可选系统。路线选择影响风险，风险越高收益越高。

### 规则草案

| 行为 | 风险变化 |
|---|---:|
| 普通战斗 | +10 |
| 精英战斗 | +20 |
| 商店 | -10 |
| 休息 | -15 |
| 事件 | -5 / +10，取决于选择 |

### 风险影响

- 增加敌人伤害或 HP。
- 增加金币奖励。
- 增加高稀有卡概率。
- 达阈值触发危机事件。

### 验收

- [ ] 风险变化在 UI 可见。
- [ ] 高风险奖励更好。
- [ ] 高风险敌人更危险。
