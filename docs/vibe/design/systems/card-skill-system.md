# 卡牌技能系统设计

## 目标

用数据驱动的技能卡支持构筑、升级、删卡和稀有度追求。

## MVP 范围

### P0
- 攻击、防御、回复 3 类基础卡。
- 卡牌费用、稀有度、效果说明。
- 出牌后扣能量并进入弃牌堆。

### P1
- 抽牌、回能、状态效果。
- 战斗奖励 3 选 1。
- 商店买卡。

### P2
- `upgradeTo` 升级链。
- 技能祭坛。
- 删卡/焚卡。

## 稀有度

| 稀有度 | 颜色 | 倍率 | MVP 用途 |
|---|---|---:|---|
| 普通 | white | 1.0 | 初始/普通掉落 |
| 优秀 | green | 1.4 | 普通奖励/商店 |
| 精良 | blue | 1.8 | 精英奖励 |
| 史诗 | purple | 2.3 | Boss/稀有事件 |
| 传说 | orange | 3.0 | P2+ |
| 神话 | red | 4.0 | P3+ |

## 技能类型

| 类型 | P0 | 说明 |
|---|---|---|
| attack | 是 | 造成伤害 |
| defense | 是 | 获得护甲 |
| heal | 是 | 恢复生命 |
| buff | P1 | 提升自身能力 |
| debuff | P1 | 削弱敌人 |
| economy | P1/P2 | 金币相关 |
| special | P2 | 改变规则 |

## 卡牌字段

| 字段 | 说明 |
|---|---|
| id | 唯一 ID |
| name | 展示名 |
| tier | 技能阶数 |
| rarity | 稀有度 |
| cost | 能量费用 |
| type | 技能类型 |
| effect | 结构化效果 |
| description | UI 描述 |
| upgradeTo | 下一阶卡牌 ID |
| characterBind | 绑定角色 |
| flavorText | 风味文本 |

## 效果解释优先级

1. 检查费用。
2. 扣除能量。
3. 根据 `type/effect` 结算。
4. 应用稀有度倍率。
5. 移动卡牌到弃牌堆。
6. 检查敌人死亡。
7. 更新消息。

## 升级链原则

- 升级保留玩法定位，不只是倍率翻倍。
- Lv1 → Lv2 → Lv3 为主。
- 不允许循环升级链。
- UI 必须显示升级前后差异。

## 验收

- [ ] 攻击/防御/回复卡都能生效。
- [ ] 稀有度颜色和倍率一致。
- [ ] 费用不足不能出牌。
- [ ] 奖励获得的卡能在后续战斗抽到。
- [ ] 升级链 ID 全部有效。
