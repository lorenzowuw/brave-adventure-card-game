# 事件系统设计

## 目标

用轻量选择题提供路线变化、资源取舍和奇幻冒险感。

## MVP 范围

### P1
- 每个事件 2-3 个选项。
- 支持金币变化。
- 支持生命变化。
- 支持获得卡牌。
- 支持无事发生。

### P2+
- 删除卡牌。
- 升级卡牌。
- 临时 Buff。
- 条件分支。

## 事件字段

| 字段 | 说明 |
|---|---|
| id | 事件 ID |
| title | 标题 |
| description | 事件描述 |
| choices | 选项列表 |
| areaId | 所属区域 |

## 选项字段

| 字段 | 说明 |
|---|---|
| id | 选项 ID |
| label | 选项按钮文本 |
| description | 选项说明 |
| effects | 结构化效果 |
| outcomeText | 选择后反馈 |

## 效果类型

| 效果 | P1 | 说明 |
|---|---|---|
| goldChange | 是 | 加/扣金币 |
| hpChange | 是 | 加/扣生命 |
| energyChange | 可选 | 改变能量 |
| cardReward | 是 | 获得指定卡 |
| removeCard | P2 | 删除卡 |
| upgradeCard | P2 | 升级卡 |
| blessingReward | P2 | 获得祝福 |

## 事件设计原则

- 每个选项都要有取舍。
- 文案短，按钮明确。
- 不出现“必选正确答案”。
- 结果即时反馈。
- 不因事件直接导致玩家困惑或卡死。

## P1 事件示例池

| 事件 | 选项 A | 选项 B | 选项 C |
|---|---|---|---|
| 受困旅人 | 帮忙得祝福 | 索报酬得金币 | 离开 |
| 路边武师 | 学习得卡 | 挑战进战斗 | 围观得少量金币 |
| 神秘商人 | 买强卡 | 讨价还价 | 拒绝 |

## 验收

- [ ] 事件能按区域筛选。
- [ ] 每个选项能正确应用效果。
- [ ] 事件完成后回到地图。
- [ ] 事件不会重复卡住当前节点。
