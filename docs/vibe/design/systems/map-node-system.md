# 地图与节点系统设计

## 目标

用有限预览的树形地图提供路线选择，同时避免玩家被过多信息压垮。

## MVP 地图结构

```text
起点前
→ 第 1 层：2-3 个节点
→ 第 2 层：2-3 个节点
→ 第 3 层：2-3 个节点
→ 第 4 层：1-2 个节点
→ Boss
```

## 节点类型

| 类型 | P0 | P1 | 说明 |
|---|---|---|---|
| battle | 是 | 是 | 普通战斗 |
| elite | 否 | 是 | 精英战斗 |
| boss | 是 | 是 | 区域 Boss |
| shop | 否 | 是 | 商店 |
| event | 否 | 是 | 随机事件 |
| rest | 否 | 是 | 休息/祝福 |
| reward | 否 | P2 | 奖励关 |
| skill_altar | 否 | P2 | 技能升级 |
| burn_altar | 否 | P2 | 删卡换收益 |

## 预览规则

- 当前层：清晰显示，可点击。
- 下一层：灰化显示，不可点击。
- 更远层：不显示。
- 未知节点：显示 `????`。
- Boss：可在末尾用轮廓或锁定图标提示。

## 地图数据字段

| 字段 | 说明 |
|---|---|
| id | 地图 ID |
| areaId | 区域 ID |
| layers | 层级数组 |
| boss | Boss 节点 |

## 节点字段

| 字段 | 说明 |
|---|---|
| id | 节点 ID |
| type | 节点类型 |
| label | UI 显示名 |
| enemies | 战斗节点引用敌人 ID |

## 推进规则

1. 玩家点击当前层节点。
2. 进入对应场景。
3. 场景完成后推进到下一层。
4. 若下一层超过普通层数，进入 Boss。
5. Boss 胜利后进入胜利结算。

## 验收

- [ ] 当前层节点可点击。
- [ ] 下一层节点不可点击。
- [ ] 点击战斗节点进入正确敌人。
- [ ] 完成节点后层数推进。
- [ ] Boss 节点能触发通关。
