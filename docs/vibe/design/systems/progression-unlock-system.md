# 成长与解锁系统设计

## 目标

区分局内成长和全局成长，形成 roguelike 重开动力。

## 局内成长

| 内容 | 死亡后是否保留 | 说明 |
|---|---|---|
| 当前角色等级 | 否 | 每局重置 |
| 当前卡组 | 否 | 每局构筑 |
| 金币 | 否 | 局内资源 |
| 遗物/被动 | 否 | 局内强化 |
| 地图位置 | 否 | 本局进度 |

## 全局成长

| 内容 | 保留 | MVP |
|---|---|---|
| 已解锁角色 | 是 | 是 |
| 已解锁祝福池 | 是 | P2 |
| 图鉴记录 | 是 | P3 |
| 全局等级 | 是 | P2/P3 |
| 成就 | 是 | P3 |
| 总局数/胜场 | 是 | 是 |

## 等级成长

| 等级 | HP 加成 | 能量加成 | 解锁 |
|---|---:|---:|---|
| Lv1 | 0% | 0% | 初始技能卡 |
| Lv2 | 10% | 5% | 第 2 技能槽 |
| Lv3 | 20% | 10% | 升级一张初始卡 |
| Lv4+ | P2 | P2 | 延后 |

## 解锁规则

| 条件 | 解锁 |
|---|---|
| 初始 | 铁壁守卫、影刃刺客、生命贤者 |
| 教程/首局后 | 太极武僧、游侠商人、圣光战士 |
| 击败 Boss1 | 财富商人、亡灵祭司、破甲战士 |
| 击败 Boss2 | 元素法师、全能贤者、格斗大师 |
| 击败 Boss3 | 冰霜祭司、荆棘守卫、隐藏角色 |

## 存档字段

| 字段 | 说明 |
|---|---|
| version | 存档版本 |
| unlockedCharacters | 已解锁角色 ID |
| unlockedBlessings | 已解锁祝福 ID |
| maxLevel | 全局等级或上限 |
| achievements | 成就 ID |
| totalRuns | 总局数 |
| totalVictories | 总胜利 |

## 验收

- [ ] 死亡后局内卡组清空。
- [ ] 胜利次数保留。
- [ ] 刷新页面后解锁角色仍可选。
- [ ] 坏存档不会导致白屏。
