# 商店与经济系统设计

## 目标

让金币成为卡组强化、删卡和风险选择的核心资源。

## MVP 范围

### P1
- 战斗奖励金币。
- 商店出售 4 张卡。
- 根据稀有度定价。
- 可购买卡牌。
- 可指定删卡。

### P2+
- 消耗品。
- 遗物。
- 技能进阶卷轴。
- 角色碎片/解锁道具。

## 金币来源

| 来源 | MVP | 说明 |
|---|---|---|
| 普通战斗 | 是 | 基础收益 |
| 精英战斗 | P1 | 更高收益 |
| Boss | P1 | 大量收益 |
| 事件 | P1 | 选项收益 |
| 经济卡 | P2 | 卡牌效果获得 |
| 风险系统 | P3 | 高风险奖励倍率 |

## 金币消耗

| 消耗 | MVP | 说明 |
|---|---|---|
| 买卡 | 是 | 主要用途 |
| 删卡 | 是 | 卡组优化 |
| 事件交易 | P1 | 神秘商人等 |
| 升级卡 | P2 | 进阶卷轴/祭坛 |
| 回复 | P2 | 商店治疗 |

## 定价建议

| 稀有度 | 基础价格 |
|---|---:|
| white | 10 |
| green | 18 |
| blue | 30 |
| purple | 50 |
| orange | 80 |
| red | 不常规出售 |

## 删卡规则

- P1 必须允许玩家指定删哪张卡，不能随机删除。
- 删卡价格初始 15。
- 同一商店可以限制删 1 次，避免过强。
- 删除后应从所有局内牌区移除。

## 验收

- [ ] 金币变化清晰显示。
- [ ] 金币不足时购买按钮禁用。
- [ ] 买到的卡能在后续战斗抽到。
- [ ] 删除的卡不会再次出现。
