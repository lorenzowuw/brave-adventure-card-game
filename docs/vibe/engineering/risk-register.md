# 工程风险登记

## 高风险

### R1：战斗状态被原地修改
- 影响：React 状态不刷新、旧状态污染、难复现 bug。
- 预防：系统函数返回新对象；禁止 push/直接改嵌套对象。
- 检查：重点看 `BattleSystem.ts`, `RunManager.ts`, `App.tsx`。

### R2：配置引用 ID 失效
- 影响：进入节点/获得卡牌时崩溃或 fallback 到错误内容。
- 预防：数据校验脚本或构建前检查。
- 检查：maps → enemies，skills.upgradeTo → skills，events.cardReward → skills。

### R3：UI 和系统重复持有规则
- 影响：改配置不生效，数值不一致。
- 预防：UI 只显示，规则只在 system。

## 中风险

### R4：卡牌效果解释器扩展失控
- 影响：每加新卡都要写特殊逻辑。
- 预防：先支持结构化通用效果，特殊卡延后。

### R5：商店/事件修改卡组不一致
- 影响：删卡后手牌/弃牌仍存在。
- 预防：定义卡牌实例 ID 或统一按 card id 移除。

### R6：localStorage 坏档白屏
- 影响：玩家无法进入游戏。
- 预防：读档 fallback 和版本字段。

## 低风险

### R7：AI 美术风格漂移
- 影响：资产不统一。
- 预防：保留 raw、使用固定 prompt、少量逐批生成。

### R8：背景干扰可读性
- 影响：UI 难读。
- 预防：低对比度背景，实机预览。
