> v4.0 — 基于《卡牌冒险者》核心理念，融入原创奇幻角色、火柴人美术与创新机制

> ⚠️ **AI-Native 开发模式**：全程依赖 AI 工具完成编码、美术、设计，无专门美术组。
> 火柴人美术风格经过精心选择——因为 AI 生成火柴人比生成精细插画稳定得多、成本低得多。
>
> ⚠️ 本文档为方向性设计参考，具体数值、角色名单、技能效果均在实现中可灵活调整

> - 技能颜色稀有度体系（白→绿→蓝→紫→红）
> - 技能升级/进化机制（1级→2级→3级）
> - 弃旧卡加速卡组循环机制

## 二、美术思路（AI-Native 生产）

### 2.1 核心理念：火柴人 + 角色特征

为了保持角色识别度，采用 **「火柴人底模 + 特征装饰」** 方案。

**为什么选择火柴人（AI 生成角度的考量）：**
- AI 画火柴人的**成功率 > 90%**，画精细插画成功率 < 30%
- 火柴人线稿简单，AI 不易出错（不多手指、不乱画五官）
- 可通过 text prompt 精确控制特征（"stick figure with sunglasses"）
- 无需训练 LoRA、无需 ControlNet，开箱即用
- 批量生成成本极低，适合迭代试错

**基本原则：**
- 所有角色的身体基底都是 **白色/浅色火柴人**（头+身体+四肢，2-4头身比例）
- 通过 **发型、配饰、体型轮廓、标志性动作** 来区分角色
- 不使用任何真实人物肖像、原有版权图像
- 整体画风统一，黑白为主 + 1-2种角色主题色点缀

### 2.2 AI 美术生产管线

**核心三步流程：**

```
Step 1                    Step 2                       Step 3
┌──────────────┐         ┌──────────────┐            ┌──────────────┐
│ 找参考图      │   →    │ AI分析特征    │    →      │ AI生成火柴人  │
│ (网络搜索/截图)│         │ (AnalyzeImage) │           │ (imagegen)    │
│              │         │ 输出特征描述   │            │ 按描述绘制    │
└──────────────┘         └──────────────┘            └──────────────┘
                              │                             │
                              ↓                             ↓
                        "圆头、大眼、绿色、              ✓ 保留核心特征
                         悲伤表情、泪滴"                  ✓ 去掉真实细节
                                                         ✓ 不构成侵权
```

**关键区别**：不是人去想 prompt → AI 生成，而是 **AI 先看原图总结特征 → AI 再用特征画火柴人**。

这样能保证：
- ✅ 一眼认出是谁
- ✅ 线条简化后不侵权
- ✅ AI 总结的特征比人脑记忆更准

### 2.3 具体操作流程（对每个角色执行）

```
[每生成一个角色，执行以下操作]

1. 准备 1-3 张该角色的参考图片（概念图/设定图）

2. 用 AnalyzeImage 分析图片，提取核心视觉特征：
   → "头部是什么形状？有什么标志性装饰？"
   → "体型是胖是瘦？有什么标志性动作/姿势？"
   → "最让人一眼认出它的 2-3 个特征是什么？"

3. 将特征描述作为 prompt，用 imagegen 生成火柴人版：
   → "A simple stick figure version of [特征描述],
      black line art on white background, game character sprite style"

4. 评估结果：路人能认出是谁吗？→ 不行就调整特征重新生成
```

**特征分析示例：**

| 角色 | AI 分析原图后提取的核心特征 | 对应火柴人方案 |
|------|---------------------------|--------------|
| 铁壁守卫 | 厚重盔甲、大盾牌、站姿沉稳 | 宽肩轮廓+矩形盾牌+盔甲线条 |
| 影刃刺客 | 紧身衣、匕首、斗篷 | 修长身形+兜帽轮廓+短刃 |
| 生命贤者 | 长袍、法杖、柔和表情 | 长袍线条+法杖+柔和圆脸 |
| 太极武僧 | 练功服、单腿站、长发 | 宽松练功服+长发+单腿姿势 |
| 圣光战士 | 铠甲+光效、长剑、金发 | 发光线条+长剑+金色头 |
| 冰霜祭司 | 冰蓝长袍、法杖、冰晶装饰 | 冰蓝色调+法杖+冰晶轮廓 |

#### 卡面图模板

```
A stick figure performing [动作描述], action lines, 
simple background, game card art style, black and white with [主题色] accents
```

#### 敌人图模板

```
A creepy stick figure monster, [怪物特征描述], 
dark tone, jagged lines, game enemy sprite style
```

### 2.4 卡牌美术风格

| 元素 | 设计 | AI 生成方式 |
|------|------|------------|
| 卡牌底色 | 浅色背景 + 角色主题色边框 | AI 生成 3-5 套模板，代码复用 |
| 卡面图 | 火柴人施展技能的简笔画（关键帧风格） | text-to-image + 去背景 |
| 文字 | 技能名用较大的手写风格字体，效果用常规字体 | 代码渲染（不需要 AI） |
| 稀有度 | 边框上色（白→蓝→紫→金） | 代码控制颜色 |
| 费用标识 | 左上角数字，用 ⚡ 统一标示 | 代码渲染 |

### 2.5 AI 辅助卡牌 / UI 元素

| 资产 | AI 生成方式 |
|------|------------|
| 卡牌边框 | 用 AI 生成 2-3 套模板，代码复用 |
| 费用图标 | AI 生成 ⚡ 风格化图标 |
| 效果文字 | 代码直接渲染（不需要美术资源） |
| 背景图 | AI 生成各区域的抽象背景（极简风格） |
| 特效 | 代码粒子/线条动画（不需要 AI） |

> **核心原则**：能用代码画的绝不生成图片，减少 AI 美术工作量。
> 火柴人本身可以用 Canvas 代码绘制，AI 只负责"设计定稿"阶段的角色形象参考。

## 三、角色系统

### 3.1 设计原则

- 开局从初始角色池中选择 1 名角色开始冒险
- 击败不同阶段的 Boss（1.0 / 2.0 / 3.0）解锁延伸角色
- 角色可通过局内战斗/任务/奖励关提升等级
- 等级提升 → 血量、能量（蓝量）等基础属性成长
- 每个角色有专属被动 + 初始技能卡（可升级/可替换）
- 角色 = 初始模板 + 养成方向，数据驱动配置

### 3.2 角色获取与全局解锁进度

玩家每次冒险从已解锁的角色池中选 1 名开始。全局解锁进度如下：

### 3.5 角色等级与属性成长

角色在冒险过程中通过以下方式获得经验：
- 击败敌人 → 经验值
- 完成奖励关 → 额外经验
- 特殊事件 → 经验/直接升级

**等级提升效果：**

| 等级 | 血量加成 | 能量加成 | 额外解锁 |
|------|---------|---------|---------|
| Lv1（初始） | 基础值 | 基础值 | 初始技能卡×1 |
| Lv2 | +10% | +5% | 解锁第2个技能卡槽位 |
| Lv3 | +20% | +10% | 可选择升级一张初始技能卡 |
| Lv4 | +30% | +15% | 解锁第3个技能卡槽位 |
| Lv5 | +45% | +20% | 可选择升级一张初始技能卡 |
| Lv6 | +60% | +25% | 解锁被动技能槽位 |
| Lv7 | +75% | +30% | 可选择升级一张初始技能卡 |
| Lv8 | +90% | +35% | 解锁第4个技能卡槽位 |
| Lv9 | +100% | +40% | 全部初始技能卡升至最高等级 |
| Lv10（上限） | +120% | +50% | 解锁最终被动槽位 |

> 每局角色等级独立，角色死亡后重置。等级上限随全局解锁提升。

## 四、卡牌技能系统

### 4.1 技能颜色稀有度体系

技能卡按强度分为 6 个颜色等级，全局统一辨识：

| 颜色 | 稀有度名称 | 强度倍率 | 获取方式 |
|------|-----------|---------|---------|
| ⚪ **白** | 普通 | ×1.0 | 初始自带、战斗掉落 |
| 🟢 **绿** | 优秀 | ×1.4 | 战斗掉落、商店购买 |
| 🔵 **蓝** | 精良 | ×1.8 | 精英掉落、商店购买 |
| 🟣 **紫** | 史诗 | ×2.3 | Boss掉落、特殊事件 |
| 🟠 **橙** | 传说 | ×3.0 | 隐藏Boss、稀有事件 |
| 🔴 **红** | 神话 | ×4.0 | 终极挑战、多张同卡合成 |

**设计意图**：玩家一眼就能判断卡牌强度，不用细读数值。颜色也作为玩家追求的目标——"如果把这章初始白卡升到红色会有多强？"

### 4.2 技能升级/进化机制（以武僧为例）

每个角色的初始技能卡可以在局内通过 **特殊事件** 或 **等级提升** 进行升级。升级后的技能保留效果类型但数值/效果增强。

**核心逻辑**：技能升级 = 效果进阶，不是简单的数值翻倍。

**示例：武僧的技能进化链**

```
┌─ Lv1: "连环掌" ──────────────────────┐
│  效果：造成 3 点伤害                   │
│  费用：1 能量                          │
│  画面提示：火柴人打出快掌的动作        │
└────────────────────────────────────────┘
                    ↓ 升级事件
┌─ Lv2: "破空掌" ──────────────────────┐
│  效果：造成 6 点伤害                   │
│  费用：1 能量                          │
│  新增：有小概率暴击（+50%伤害）        │
└────────────────────────────────────────┘
                    ↓ 升级事件
┌─ Lv3: "太极破" ──────────────────────┐
│  效果：造成 10 点伤害                  │
│  费用：1 能量                          │
│  新增：暴击率提升至 30%               │
└────────────────────────────────────────┘
```

**升级方式**：
- 角色达到 Lv3/Lv5/Lv7 时可以选择 **升级一张已有的初始技能卡**
- 在特殊事件节点遇到"技能升级祭坛"
- 商店购买"技能进阶卷轴"

### 4.3 技能类型框架

| 类型 | 作用 | 效果特征 | 技能名示例 |
|------|------|---------|------------|
| **攻击** | 对敌人造成伤害 | 单体/AOE/连击/真实伤害 | "连环掌"、"暗影突袭" |
| **防御** | 获得护甲/减伤 | 护甲值/百分比减伤 | "坚守防线"、"铁壁" |
| **回复** | 恢复生命 | 直接回血/持续回血 | "治愈之光"、"再生" |
| **增益** | 提升自身能力 | 加攻/加防/加能量/加抽牌 | "战意昂扬"、"专注" |
| **减益** | 削弱敌人 | 降攻/降防/持续伤害/眩晕 | "破甲"、"虚弱诅咒" |
| **经济** | 获取资源 | 金币/抽牌/能量回复 | "高价悬赏"、"贪婪" |
| **特殊** | 改变规则 | 弃牌/转换/召唤/斩杀 | "混沌之力"、"献祭" |

### 4.4 技能卡数据结构

```json
{
  "id": "monk_strike_1",
  "name": "连环掌",
  "tier": 1,
  "color": "white",
  "cost": 1,
  "type": "attack",
  "effect": {
    "damage": 3,
    "crit_chance": 0
  },
  "upgrade_to": "monk_strike_2",
  "flavortext": "以柔克刚，四两拨千斤。",
  "character_bind": "太极武僧"
}
```

每张卡配置了 `upgrade_to` 字段指向升级版，游戏中触发升级事件时直接读取替换。

### 4.5 技能获取途径

| 途径 | 获得 | 说明 |
|------|------|------|
| **初始自带** | 角色初始技能（白色） | 每个角色开局 1-2 张专属技能卡 |
| **战斗掉落** | 随机技能卡 | 颜色与敌人强度正相关 |
| **精英/Boss掉落** | 高品质技能卡（蓝/紫） | 必定掉落 |
| **商店购买** | 各色技能卡 | 明码标价，越贵越好 |
| **事件获得** | 特殊技能卡 | 选择分支奖励 |
| **技能升级祭坛** | 已有技能升级 | 白→绿→蓝→紫（一步步升） |
| **卡牌合成**（可选） | 低品质合高品质 | 3张同色合成更高1级 |

### 4.6 弃牌/换牌机制（加速卡组循环）

为了让玩家的卡组更精简、强势卡更快上手，设计以下机制：

| 机制 | 触发方式 | 效果 |
|------|---------|------|
| **删卡** | 商店/事件中选择"删除一张卡" | 从卡组中永久移除一张卡 |
| **遗忘** | 获得新强卡时可以选择"遗忘一张旧卡" | 有舍才有得 |
| **替换** | 升级技能时可以选择替换原技能 | 初始卡→高级卡的进化路径 |
| **精简奖励** | 战斗胜利奖励可选"金币"或"删卡" | 让玩家自己权衡 |
| **焚卡炉** | 特殊事件节点 | 弃掉N张卡获得强力Buff |

**设计意图**：让玩家不断优化卡组，避免卡组臃肿抽不到关键牌。"好的卡组是剪出来的"。

### 4.7 技能命名原则

**命名原则：**
- 命名直观反映技能效果
- 风格统一，符合奇幻世界观
- 简洁有力，便于玩家记忆

**示例池（仅作启发，不锁定）：**

```
攻击系：
  "连环掌" → 多段连击
  "暗影突袭" → 真实伤害
  "破甲斩" → 伤害+降防
  "舍身击" → 自残高伤
  "蓄力一击" → 等待后爆发
  "灼热锋刃" → 持续伤害
  "致命一击" → 斩杀
  "金币投掷" → 伤害+获得金币

防御/回复系：
  "铁壁" → 高护甲
  "坚韧" → 受伤后回血
  "冥想" → 蓄力
  "牺牲" → 弃牌换护甲
  "守护之盾" → 护甲+抽牌
  "生命之泉" → 回血+抽牌

增益/减益系：
  "战意昂扬" → 永久升级一张牌
  "破甲" → 降防
  "狂暴" → 加攻降防
  "灼烧" → 持续火伤
  "虚弱领域" → 敌方全体弱化
  "嘲讽" → 强制攻击自身

特殊/趣味系：
  "混沌之力" → 重洗所有手牌
  "贪婪" → 多选一变成全拿
  "掠夺" → 获得敌方金币
  "末日审判" → 强力AOE
  "命运骰子" → 随机高额效果
  "能量抽取" → 减少敌人能量
```

## 五、战斗系统

### 5.1 战斗流程

```
回合开始 → 抽牌(5张) → 获得能量(6-8点) → 玩家出牌阶段
    → 结束回合 → 敌人行动(显示意图) → 回合结束
    → 下一回合（重复）
```

**关键规则：**
- 未使用的能量在回合结束时清空（不累积）
- 手牌上限 10 张，超出时弃牌
- 牌库抽空后弃牌堆洗回牌库
- 敌人行动意图每回合显示给玩家

### 5.2 核心数值

| 参数 | 说明 | 初始典型值 | 随等级成长 |
|------|------|-----------|-----------|
| 血量（HP） | 角色生命值，归零则死亡 | 60-100 | +10%~+120% |
| 能量（蓝量/MP） | 每回合可用行动力 | 6-8 | +5%~+50% |
| 手牌上限 | 最多持有的手牌数 | 10 | 固定 |
| 每回合抽牌 | 每回合抽牌数 | 5 | 部分角色成长 |
| 护甲 | 减伤值，每回合重置 | 0 | 不继承 |
| 卡牌费用 | 1-5 点不等 | 白色1-2，紫色3-5 | 颜色越高费用越高 |

> 黄色条 = 血量，蓝色条 = 能量，绿色数字 = 护甲

### 5.3 角色等级成长在战斗中的体现

```
角色 Lv1 进入战斗 → 血量 80，能量 6
经历 N 场战斗后升级 → Lv3
→ 血量 +20% = 96，能量 +10% = 7
→ 解锁第3个技能卡槽位
→ 可以选择升级一张初始技能卡
```

### 5.4 敌人AI框架

- 敌人有预设的 **行为模式**（意图系统，显示给玩家）
- 意图类型：攻击、防御、Buff、Debuff、召唤
- 多种难度可配：
  - 普通怪：1-2 种意图循环
  - 精英怪：2-3 种交替 + 特殊技能
  - Boss：3+ 种循环 + 阶段转换（血量低于50%进入新阶段）

### 5.5 状态效果系统

| 状态 | 效果 | 常见来源 |
|------|------|---------|
| 灼烧 | 每回合受到X点伤害，持续N回合 | 火焰技能 |
| 中毒 | 每回合受到X点伤害（可叠加） | 毒系技能 |
| 脆弱 | 受到伤害增加X% | "破甲" |
| 虚弱 | 造成的伤害减少X% | "虚弱诅咒" |
| 护甲 | 抵消伤害，回合结束清空 | 防御技能 |
| 敏捷 | 额外抽牌/能量 | "战意昂扬" |
| 嘲讽 | 强制攻击目标 | "嘲讽" |
| 眩晕 | 跳过回合 | 控制技能 |

> 状态系统同样是数据驱动，后期可随意增删。

### 5.6 奖励关/任务系统

除常规节点外，地图上可能出现特殊节点：

| 节点类型 | 内容 | 奖励 |
|---------|------|------|
| **奖励关** | 挑战特殊敌人/限时击杀 | 大量经验 + 高品质卡牌 |
| **训练场** | 无风险战斗（不掉血） | 少量经验 + 金币 |
| **试炼** | 连续3场战斗不休息 | 稀有卡 + 大量经验 |
| **冒险问答** | 答题挑战 | 特殊消耗品/经验 |

## 六、创新系统

### 6.1 元素共鸣（Element Resonance）

**核心思路**：特定的角色组合/卡牌组合触发额外效果，鼓励玩家探索搭配。

**设计要点（保持开放）：**
- 共鸣不限于双角色，可以是"角色+特定卡牌"、"特定多张卡牌组合"
- 共鸣效果 = 锦上添花，不依赖也能通关
- 共鸣通过游戏中"图鉴"系统记录和发现
- 共鸣池极易扩展，增删一个组合只需改JSON

示例思路：

| 组合条件 | 共鸣名 | 效果 |
|---------|--------|------|
| 铁壁守卫 + 生命贤者 | "铁壁守护" | 每回合获得额外护甲 |
| 连续打出3张攻击牌 | "三重打击" | 第3张伤害翻倍 |
| 太极武僧 + 圣光战士 | "光武合一" | 双方攻击力提升 |
| 使用3张不同费用牌 | "完美节奏" | 抽一张牌 |

### 6.2 冒险祝福（Adventure Blessing）

**核心思路**：每次进入战斗前，从祝福池中随机刷出若干条"祝福"，选一条作为本场战斗的临时Buff。

**设计要点：**
- 祝福池随游戏进度扩展（击败Boss/解锁新区域解锁新祝福）
- 祝福效果 = 正面的临时增益，不强但有用
- 祝福文字简洁明了，增加代入感

示例祝福池：

| 祝福 | 效果 |
|------|------|
| "先发制人" | 第一次攻击伤害翻倍 |
| "财运亨通" | 金币获取+30% |
| "绝境重生" | 血量第一次低于50%时回30% |
| "思维敏捷" | 抽牌数+1 |
| "能量充盈" | 能量上限+2 |
| "坚不可摧" | 敌人攻击-20% |
| "初始护盾" | 初始护甲+10 |
| "幸运眷顾" | 稀有卡出现率提高 |

### 6.3 风险系统（Risk System）[可选]

**核心思路**：风险越高收益越高，鼓励玩家挑战极限。

- 风险值 0-100，影响敌人强度和奖励质量
- 选择战斗 → 风险上升
- 选择商店/休息 → 风险下降
- 风险超过阈值触发"危机事件"（精英战/稀有奖励）
- 风险归零触发"安逸事件"（简单战/少量奖励）

> 此系统作为可选复杂度，初期可做简化版或不加入。

### 6.4 商店与成长

**商店卖什么：**
- 卡牌（通用+角色专属）
- 遗物（被动效果，整局有效）
- 消耗品（回血/回能量/一次性效果）
- 角色碎片/解锁道具（若采用解锁制）

**商店货币**：金币（战斗/事件获得）

**成长反馈链条：**
```
战斗胜利 → 获得金币+经验+卡牌选择
       → 金币在商店强化卡组
       → 经验提升角色等级
       → 等级提升解锁更多卡牌位/能量上限
```

## 七、地图与关卡设计

### 7.1 世界观框架：奇幻大陆

游戏分为若干个"区域"，每个区域对应一种奇幻场景。区域**可自由增删**，不固定顺序。

| 区域代号 | 主题氛围 | 敌人画风 | Boss | Boss编号 |
|---------|---------|---------|------|---------|
| **迷雾森林** | 幽暗神秘，古木参天 | 森林生物、树精、暗影兽 | **树精之王** | 1.0 |
| **古城遗迹** | 荒废文明，机关遍布 | 石像兵、幽灵、机关守卫 | **遗迹守灵** | 1.0 |
| **烈焰之地** | 火山地狱，熔岩横流 | 火元素、恶魔、岩浆兽 | **炎魔领主** | 2.0 |
| **冰封神殿** | 极寒之地，风雪肆虐 | 冰元素、雪怪、冰龙 | **冰霜巨龙** | 2.0 |
| **混沌深渊** | 终极禁区，法则混乱 | 混沌生物、暗影领主 | **混沌之主** | 3.0 |

### 7.2 树形图地图结构（核心设计）

地图采用 **树形分支结构**，展示给玩家的方式如下：

```
【当前所在层】
                                                    
层1         ■ 出发                                  
               ↓                                    
层2      ┌────├────┐                               
         ■    ■    ■                               
       战斗  商店  事件                              
         ↓    ↓    ↓                               
层3     ■    ■    ■                                
       战斗  精英  休息                              
         ↓    ↓    ↓                               
层4     ■────■────■  ← 路径在此交汇                 
               战斗                                  
                 ↓                                  
层5         ■  Boss                                 

【预览：再下层入口将在通关本层后解锁】
```

**树形图设计要点：**

| 特性 | 说明 |
|------|------|
| **分支选择** | 每层有 2-3 个节点供选择，选后不可回头 |
| **有限预览** | 玩家只能看到当前层 + 下一层的节点内容（"前方是战斗还是商店？"） |
| **路径交汇** | 不同路径在关键节点重新汇合，不会无限分支 |
| **隐藏节点** | 部分路线需要特定条件才解锁（如特定角色/特定卡牌） |
| **回退机制** | 核心路线保证玩家总能到达Boss，不因选错路卡死 |

**玩家看到的实际效果：**
```
       当前所在位置 ▼
       ┌─────────────┐
       │   ■ 战斗    │ ← 当前层
       │   ■ 商店    │
       │   ■ 事件    │
       └─────────────┘
            ↓
       ┌─────────────┐
       │   ■ 精英    │ ← 预览下一层（灰色/模糊）
       │   ■ 休息    │
       │   ????      │ ← 未知节点
       └─────────────┘
再往下就要通关当前层才显示
```

### 7.3 节点类型

| 节点 | 图标 | 内容 | 奖励 |
|------|------|------|------|
| **普通战斗** | ⚔️ | 1-3 个普通敌人 | 经验+金币+卡牌选择 |
| **精英战斗** | ⚠️ | 强力敌人，有特殊机制 | 大量经验+蓝/紫卡 |
| **Boss战** | 👑 | 区域关底 | Boss掉落+大量金币 |
| **商店** | 🏪 | 买卡/删卡/买消耗品 | 花费金币 |
| **事件** | ❓ | 随机选择题 | 依选择而定 |
| **休息** | 🏕️ | 回血+选祝福 | 30%回血+Buff |
| **奖励关** | 🎁 | 特殊挑战 | 经验+高品质卡 |
| **技能祭坛** | 🔥 | 升级一张已有技能卡 | 技能等级+1 |
| **焚卡炉** | 🔥 | 弃卡换Buff | 删卡换强力Buff |

### 7.4 事件示例

所有事件 = 选择题，玩家在 2-3 个选项中权衡：

**"在森林深处发现一个受困的旅人"**
- A. 伸出援手 → 获得临时队友/祝福
- B. 索要报酬才帮忙 → 获得金币
- C. 绕道走 → 无事发生

**"一位老者在路边展示祖传武艺"**
- A. 虚心求学 → 获得卡牌"连环掌"
- B. 提出挑战 → 战斗（赢了获得更多奖励）
- C. 围观后离开 → 获得少量金币

**"你发现了一座古老的技能升级祭坛"**
- A. 献上初始技能卡 → 升级为Lv2（白→绿）
- B. 献上金币 → 随机升级一张卡
- C. 离开

**"一个神秘商人想跟你做一笔交易"**
- A. 接受交易 → 获得强力卡牌但损失金币
- B. 拒绝 → 无事发生
- C. 讨价还价 → 以更低价格成交

### 7.5 死亡与成长（Roguelike循环）

- 角色死亡 → 本次冒险结束
- **局内失去**：当前角色等级、卡组、金币、遗物、所有进度
- **全局保留**：
  - 已解锁的角色（可下次选用）
  - 已解锁的祝福池
  - 图鉴记录
  - 全局等级/成就
- 每次重开 = 新的卡组构筑起点，但角色池更丰富

## 八、游戏整体流程与全局进度

### 8.1 一局游戏的完整循环

```
┌───────────────────────────────────────────────────────┐
│               一局游戏的全流程                           │
│                                                         │
│  选角色 → 看树形图 → 选路径 → 进节点                    │
│    ↓                                                     │
│  战斗节点：打怪 → 经验+金币+选卡                        │
│  事件节点：选择分支 → 奖励/惩罚                          │
│  商店节点：买卡/删卡/回血                                │
│  休息节点：回血+祝福                                    │
│  技能祭坛：升级技能                                      │
│  奖励关：特殊收益                                        │
│    ↓                                                     │
│  逐步推进 → 打 Boss → 通关/死亡                          │
│                                                         │
│  死亡 → 回到选人界面，保留全局解锁内容                   │
│  通关 → 解锁新角色+新区域+提升全局等级                   │
└───────────────────────────────────────────────────────┘
```

### 8.2 全局进度与局内进度的关系

```
【全局进度】（跨局保留）
├── 已解锁角色（随 Boss 击败逐步解锁）
├── 已解锁祝福池
├── 图鉴记录（遇到的敌人/卡牌）
├── 全局等级（影响初始可选内容）
└── 成就系统

【局内进度】（一局内有效，死亡清空）
├── 当前角色（选人时确定）
├── 角色等级 + 属性成长
├── 卡组（初始卡 + 获得的卡）
├── 金币
├── 遗物/被动
└── 地图推进位置
```

### 8.3 新手引导流程

为让玩家不摸不清头脑，引入分阶段引导：

| 阶段 | 解锁内容 | 引导提示 |
|------|---------|---------|
| **第一局** | 可选铁壁守卫/影刃刺客/生命贤者（3选1） | 基础教程：怎么打牌、怎么走路 |
| **第一局 战斗后** | 解锁卡牌选择、升级概念 | 提示选卡策略、技能升级 |
| **击败 1.0 Boss** | 解锁新角色、新区域 | 提示角色养成、树形图选路 |
| **击败 2.0 Boss** | 解锁弃卡/合成、祝福系统 | 提示卡组精简、祝福策略 |
| **击败 3.0 Boss** | 全部解锁 | 自由搭配阶段 |

### 8.4 为什么玩家不会"摸不清头脑"

| 设计手段 | 解决什么问题 |
|---------|------------|
| **颜色稀有度** | 拿到卡牌一眼知道好坏，不需要算数值 |
| **敌人意图显示** | 知道下回合敌人要干嘛，打牌有目标 |
| **树形图有限预览** | 只看得到接下来1-2步，不 overwhelm |
| **角色定位标签** | 选人时知道这个角色是"能打"还是"能抗" |
| **技能升级可视化** | 连环掌→破空掌→太极破，有明确的变强感 |
| **分阶段引导** | 新手内容逐步释放，不一股脑全塞 |

### 10.2 AI 辅助编码策略

|------|---------|---------|

### 10.3 数据驱动架构（核心设计原则）

所有游戏内容 = 配置文件，不改代码就能改内容：

```
project/
├── data/
│   ├── characters.json     # 角色列表及属性
│   ├── cards.json          # 卡牌列表及效果
│   ├── enemies.json        # 敌人配置
│   ├── maps.json           # 地图及节点
│   ├── events.json         # 事件池
│   ├── blessings.json      # 祝福池
│   └── combos.json         # 元素共鸣表
├── src/
│   ├── core/               # 战斗引擎
│   ├── ui/                 # UI渲染
│   ├── ai/                 # 敌人AI
│   └── assets/             # 美术/音效
└── index.html
```

**优势**：
- 增删角色只需改 JSON，不动逻辑
- 平衡调整改数值就行
- 可以随时加新卡牌/新事件
- 甚至可以让社区做mod

## 十三、设计原则总结

1. **AI-Native** — 所有编码、美术、设计全部依赖 AI，人工角色是提需求和验收
2. **数据驱动** — 所有内容可配置，不改代码
3. **火柴人美术** — AI 生成稳定、低成本、版权安全
4. **原创角色** — 不碰真实人物和版权形象
5. **借鉴骨架，替换血肉** — 玩法框架参考，内容完全自创
6. **保持灵活** — 本文档是方向不是锁死的规格，随时可以调整
7. **先做核心，再做花哨** — P0先把战斗做出来，创新系统逐步加
