# 《勇者大冒险》验收清单

## 通用 Done Definition

每个任务完成前必须满足：

- [ ] 没有引入与任务无关的改动。
- [ ] TypeScript 构建通过：`npm run build`。
- [ ] 玩法改动有手动验收步骤。
- [ ] 配置改动检查引用 ID 有效。
- [ ] UI 改动在主要屏幕尺寸下可读。
- [ ] 状态更新不直接 mutate 旧对象。

## P0 验收：核心战斗原型

### 角色选择
- [ ] 初始界面显示至少 3 个角色。
- [ ] 每个角色显示定位、HP、能量、被动。
- [ ] 点击已解锁角色进入探索。
- [ ] 未解锁角色不可选。

### 地图入口
- [ ] 探索界面显示当前可选节点。
- [ ] 点击普通战斗节点进入战斗。
- [ ] 节点引用的敌人 ID 有效。

### 战斗 UI
- [ ] 显示玩家 HP/能量/护甲。
- [ ] 显示敌人 HP。
- [ ] 显示敌人意图。
- [ ] 显示手牌。
- [ ] 能量不足的卡有禁用反馈。

### 战斗规则
- [ ] 攻击牌会造成伤害。
- [ ] 防御牌会获得护甲。
- [ ] 回复牌会恢复生命且不超过上限。
- [ ] 出牌会扣能量。
- [ ] 出牌后卡进入弃牌堆。
- [ ] 结束回合后敌人执行意图。
- [ ] 新回合能量恢复，护甲清零。
- [ ] 牌库空时弃牌堆能洗回牌库。

### 结算
- [ ] 敌人死亡后给金币。
- [ ] 敌人死亡后给经验。
- [ ] 玩家死亡进入失败界面。
- [ ] 胜利后能返回探索或进入奖励。

## P1 验收：完整一局 MVP

### 地图
- [ ] 地图至少 4 层 + Boss。
- [ ] 当前层可点击。
- [ ] 下一层只预览不可点击。
- [ ] Boss 节点在末尾出现。
- [ ] 已完成节点不会重复进入。

### 奖励
- [ ] 战斗胜利后出现奖励选择。
- [ ] 可选择卡牌加入卡组。
- [ ] 可跳过或拿金币。
- [ ] 奖励卡后续能抽到。

### 商店
- [ ] 商店显示至少 4 个商品。
- [ ] 金币足够可购买。
- [ ] 金币不足不可购买。
- [ ] 购买后商品消失。
- [ ] 可以指定删除一张卡。

### 事件
- [ ] 事件显示标题、描述、选项。
- [ ] 选择能改变金币/血量/卡组。
- [ ] 事件完成后回到地图。

### 休息
- [ ] 可回复生命。
- [ ] 可选择祝福。
- [ ] 祝福能在后续战斗生效。

### Boss 与存档
- [ ] Boss 胜利进入胜利界面。
- [ ] 胜利次数写入 localStorage。
- [ ] 刷新页面后胜利次数保留。
- [ ] 解锁角色在下一局可见。

## P2 验收：构筑深度

### 卡牌升级
- [ ] 可升级卡显示升级目标。
- [ ] 升级后旧卡被替换。
- [ ] 升级不是简单数值翻倍，至少有一个效果变化。
- [ ] 升级链不会循环。

### 删卡
- [ ] 玩家能指定删卡。
- [ ] 删除后所有牌区不再出现该卡。
- [ ] 删卡有成本或机会成本。

### 角色扩充
- [ ] 6 个初始角色都能完整开局。
- [ ] Boss1 解锁角色能在通关后出现。
- [ ] 每个角色至少有 1 个明显不同的被动体验。

## 美术验收

### 角色
- [ ] 128px 下能区分角色。
- [ ] 角色使用统一火柴人底模。
- [ ] 每个角色有 1-2 个主题色。
- [ ] 不包含文字、水印、版权形象。

### UI
- [ ] 文字不由 AI 图片生成。
- [ ] 卡牌稀有度颜色清楚。
- [ ] 地图节点 64px 下可识别。
- [ ] 背景不影响文字阅读。

### 动效
- [ ] 出牌反馈小于 0.8 秒。
- [ ] 伤害/回复/护甲反馈一眼可读。
- [ ] 动效不会阻塞操作过久。

## 发布前验收

- [ ] 无控制台红色错误。
- [ ] 首屏加载正常。
- [ ] 新玩家能完成第一场战斗。
- [ ] 有重置存档入口。
- [ ] Web build 可部署。
