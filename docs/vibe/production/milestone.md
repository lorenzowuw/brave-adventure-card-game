# 《勇者大冒险》Milestone Plan

> 只把大设计拆成可验收阶段。每阶段都必须能运行、能手动测试。

## P0 / M01：核心战斗原型

### 目标

跑通“选择角色 → 进入战斗 → 出牌 → 敌人行动 → 胜利/失败”的最小闭环。

### 必须做

- 3 个初始角色：铁壁守卫、影刃刺客、生命贤者。
- 每个角色至少 1 张初始技能卡。
- 1 个普通敌人。
- 抽牌、能量、手牌、出牌、弃牌堆/牌库重洗。
- 敌人显示下一步意图。
- 玩家胜利后回到探索界面。
- 玩家死亡后进入失败界面。

### 明确不做

- 多区域。
- 多敌人同场。
- 商店、事件、休息。
- 卡牌升级。
- 全局解锁。
- AI 生成正式资产。

### Exit Criteria

- `npm run build` 通过。
- 选择任一 P0 角色能进入战斗。
- 至少能打出 3 张不同类型卡牌。
- 敌人每回合按意图行动。
- 战斗胜利和失败都能进入正确界面。

## P1 / M02：完整一局 MVP

### 目标

跑通“选角色 → 树形地图 → 多节点 → Boss → 结算/解锁”的完整一局。

### 必须做

- 树形地图至少 4 层 + 1 个 Boss。
- 节点类型：普通战斗、商店、事件、休息、Boss。
- 战斗奖励：金币、经验、3 选 1 卡牌。
- 商店：买卡 + 删卡。
- 事件：至少 3 条事件，每条 2-3 个选择。
- 休息：回血或祝福三选一。
- 角色等级：Lv1-Lv3，升级影响 HP/能量。
- 击败 Boss 后 localStorage 记录胜利次数。

### 明确不做

- 5 个区域全量。
- 14 个角色全量平衡。
- 元素共鸣。
- 风险系统。
- 图鉴。

### Exit Criteria

- 玩家可以完整通关或死亡。
- 通关后刷新页面仍能看到全局记录。
- 不修改代码，只改 JSON 可以新增一张战斗卡。
- 不修改代码，只改 JSON 可以新增一个事件。

## P2 / M03：内容扩充与升级链

### 目标

让 MVP 从“能玩一局”变成“有构筑目标”。

### 必须做

- 6 个初始角色完整配置。
- 每个角色至少 3 张专属技能升级链。
- 普通/精英/Boss 敌人分层。
- 技能祭坛节点。
- 焚卡炉节点。
- 祝福池扩展到至少 8 条。
- Boss 1.0 解锁 3 个延伸角色。

### 明确不做

- 所有 Boss 2.0/3.0 完整内容。
- 隐藏角色。
- 创意工坊。

### Exit Criteria

- 玩家能通过技能升级明显改变卡组强度。
- 删除旧卡能提升关键牌上手频率。
- 击败 1.0 Boss 后下一局可选择新角色。

## P3 / M04：差异化系统

### 目标

加入能体现本作独特性的系统，但不破坏 MVP。

### 候选系统

- 元素共鸣。
- 风险系统。
- 图鉴/成就。
- 多区域主题轮换。
- 更多火柴人视觉动作。

### 进入条件

- P1/M02 的完整一局稳定。
- P2/M03 的卡牌升级和删卡闭环有效。
- 玩家反馈确认“构筑选择有趣”。

### Exit Criteria

- 至少 1 个差异化系统能被玩家主动感知。
- 系统可通过配置扩展，不需要大改战斗核心。

## P4 / M05：发布打磨

### 目标

让游戏适合公开试玩。

### 必须做

- 新手引导。
- 音效/BGM。
- 移动端适配检查。
- 存档重置入口。
- 错误兜底界面。
- 核心流程 E2E。

### Exit Criteria

- 新玩家不看设计文档也能完成第一场战斗。
- 构建产物可部署到静态 Web 服务。
- 核心流程无控制台错误。
