# 《勇者大冒险》细粒度任务拆解

> 拆得尽量细。每个任务都应该能独立完成、独立验收。
> 状态建议：`[ ]` 未开始 / `[~]` 进行中 / `[x]` 完成 / `[!]` 阻塞。

## 0. 通用执行规则

- 每个编码任务开始前先读相关文件。
- 每个 TS/TSX 修改后运行 `npm run build`。
- 每个玩法任务都写手动验收路径。
- 不为未来系统提前抽象。
- 不改无关格式。
- 所有状态更新保持不可变。
