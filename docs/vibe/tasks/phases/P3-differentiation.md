# P3 任务：差异化系统

## 目标

加入可被玩家感知的独特系统。

## 分工原则

- 成员 A：新系统底层状态、规则计算、存档结构。
- 成员 B：配置内容、图鉴/UI 展示、体验验收。

## 候选一：元素共鸣

负责人：成员 A  
协作：成员 B

- [x] 新增 combos 配置。
- [x] 记录出牌序列。
- [x] 匹配连续攻击。
- [x] 触发共鸣效果。
- [x] 记录图鉴。
- [x] 成员 B 负责共鸣 UI、图鉴展示和配置文案。

## 候选二：风险系统

负责人：成员 A  
协作：成员 B

- [x] RunState 增加 risk。
- [x] 节点选择影响 risk。
- [x] risk 影响敌人强度。
- [x] risk 影响奖励。
- [x] 危机事件。
- [x] 成员 B 负责地图风险展示和事件文案。

## 候选三：图鉴/成就

负责人：成员 B  
协作：成员 A

- [x] 记录遇到的敌人。
- [x] 记录获得过的卡。
- [x] 记录触发过的共鸣。
- [x] UI 展示。
- [x] 成员 A 负责存档字段和写入时机。

## 验收

负责人：成员 B 主验收，成员 A 确认系统稳定。

- [x] 至少一个系统能明显改变玩家决策。
- [x] 系统不破坏 P1 完整一局。
- [x] 可通过配置扩展。
